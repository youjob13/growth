## Critical Performance Metrics

- First paint - момент, когда приложение загрузило достаточно данных и ресурсов, чтобы отрисовать первый - начальный - кадр
- Time to interactive - момент, когда пользователю становится доступна возможность нажать кнопку, а приложение может ему ответить
- Full Load - момент, когда весь пользовательские интерфейс отрисован и доступен для пользователя
