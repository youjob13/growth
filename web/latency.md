## Время ожидание (задержка сети)
Время, которое происходит с момента старта запроса до момента получения ответа. При запросе первых 14kb время ожидания дольше из-за DNS, TCP handshake, TLS negotiation.

1. Sending - время необходимое для отправки HTTP запроса на сервер
2. Waiting - работа сервера
3. Receiving - загрузка ответа. Скорость сети + размер файла
