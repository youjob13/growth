## Виды мониторинга

### Real User Monitoring (RUM)

Лучше подходит для понимания долгосрочных трендов

Измеряет производительность приложения на устройствах конечных пользователей.

### Синтетический мониторинг

Лучше подходит для тестирования регрессий, их быстрого обнаружения и быстрой реакции в процессе разработки

Мониторинг производительности в "лабораторных" условиях. Тестируются не настоящие пользователи, но заранее определённый набор инструкций, который выполняется в предопределённом окружении
